# Car Sales Analysis Using Microsoft Excel

## Project Overview

This project involves analysing car sales data using Microsoft Excel. The dataset contains information about car models, dealer IDs, quantities sold, dates, and profits.

The objective is to organise and summarise the sales data using Pivot Tables and represent key findings through Pivot Charts.

## Course & Assignment Context

This project was completed as part of the **Data Visualization and Dashboards with Excel and Cognos** course on [Coursera](https://www.coursera.org/learn/data-visualization-dashboards-excel-cognos/home/welcome), offered under the **IBM Data Analyst Professional Certificate**.

## Tasks Performed

### 1. Quantity Sold by Dealer ID
- Created a Pivot Table to calculate the total quantity of cars sold by each dealer.
- Sorted the results based on quantity sold.
- Created a Bar Chart to compare sales quantities across dealers.

### 2. Profit by Date and Model
- Created a Pivot Table to summarise profits by date and car model.
- Created a Line Chart to visualise profit trends across different car models over time.

### 3. Profit by Year and Dealer ID
- Created a Pivot Table to analyse dealer-wise profits across different years.
- Created a Column Chart to compare profitability.
- Customised the chart by formatting the data columns in red.

### 4. Profit of Hudson Models by Dealer ID
- Created a Pivot Table to calculate profits generated by the Hudson car model across different dealers.
- Created a Line Chart to visualise dealer-wise profit distribution.
- Customised the chart by removing horizontal gridlines, positioning the legend on the right, and changing the series outline colour to green.
